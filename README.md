# vrout

VPN client for Windows with visual routing and mihomo.

- [Windows x64 downloads](https://github.com/sellerrest/vrout/releases)
- [Mihomo builds and corresponding sources](https://github.com/sellerrest/vrout-core)
- [Ready-to-use routing lists](https://github.com/sellerrest/vrout-rules)

Download the ZIP and extract its contents together before opening vrout.exe.
